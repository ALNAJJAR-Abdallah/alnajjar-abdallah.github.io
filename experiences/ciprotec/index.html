Stage · 2026 · 2 semaines

Suivi des factures et relances WhatsApp

Une application qui suit les factures et leurs échéances, puis relance automatiquement les clients par WhatsApp.

Contexte

CIPROTEC, stage de deux semaines en développement Python en 2026.

Problème initial

Suivre les factures de l’entreprise et leurs échéances, puis relancer les clients à partir de leurs coordonnées.

Ma contribution personnelle

  • J’ai développé le backend Python qui traite les informations de facturation, les dates et les numéros des clients.
  • J’ai construit l’interface Streamlit de suivi.
  • J’ai mis en place les relances WhatsApp au fil des échéances, avec les services Meta for Developers.

Fonctionnalités réalisées

Suivi des factures
Factures, échéances et coordonnées clients réunies dans une même application.
Interface Streamlit
Une interface pour consulter et suivre les informations.
Relances automatiques
Envoi de relances WhatsApp selon les dates d’échéance, via Meta for Developers.

Technologies utilisées

  • Python
  • Streamlit
  • WhatsApp
  • Meta for Developers

Résultat observable

Une application qui associe le suivi des factures et l’envoi automatique de relances selon les dates d’échéance.
